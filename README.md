# ARGUS

**Adaptive Real-time Global Understanding System**

一套在 3D 太陽系場景上呈現全球情勢的情報儀表板。新聞、太空動態與地緣事件經由本機 AI 分析後，標記在地球表面或對應天體的軌道位置上。

設計目標不是做成遊戲，而是借用戰情室的資訊設計手法 —— 讓使用者一眼掌握全局，而不是逐條讀新聞。

> 所有 AI 推理都在本機執行，資料不會送往任何外部服務。

---

## 一眼讀懂的資訊設計

ARGUS 的每個事件標記都同時傳達三件事，各自使用**獨立的視覺通道**，互不干擾：

| 通道 | 表達 | 呈現 |
|---|---|---|
| **顏色** | 嚴重程度 | 危急 / 高 / 中 / 低 |
| **形狀** | 事件類別 | 九種類別各有專屬圖形 |
| **外框** | 來源可信度 | 實線＝已證實、虛線＝單一來源、點線＝未經查證 |

這代表你不需要對照圖例，就能區分「一則未經證實的危急衝突」和「一則已多方證實的中度經濟事件」—— 它們的顏色、形狀、外框全都不同。

## 核心功能

### 🌍 太陽系場景

- **完整 3D 太陽系**：30 餘個天體，依真實克卜勒軌道根數排列
- **與現實同步**：公轉、自轉、日照方向與晝夜分界線（terminator）皆對應真實時間
- **地球高解析材質**：近距離自動切換 8K 貼圖，含城市夜燈
- **程序化星雲背景**：以著色器即時生成，濃度可在設定中調整
- **貼近天體時自動正立**：北極朝上，拉遠後恢復真實軸傾角
- **距離感應的鏡頭手感**：越接近地表，旋轉越慢，避免在近距離下輕輕一動就轉過頭

| 操作 | 行為 |
|---|---|
| 滾輪 | 縮放（不會穿入天體內部） |
| 右鍵拖曳 | 環繞當前目標旋轉 |
| 左鍵拖曳 / `WASD` | 平移視角 |
| 點擊天體 | 平滑聚焦並拉近 |

### 📊 全域態勢列

畫面頂端常駐，不需點擊就能回答「現在世界是什麼狀態」：

- **態勢**：各嚴重等級的事件總數，點擊即跳至該等級最新一則
- **趨勢**：過去 6 小時與前 6 小時的類別消長
- **節奏**：24 小時進件量長條圖，依嚴重度著色
- **覆蓋**：來源數、AI 服務狀態、最近一次進件距今多久

### 🕐 時間回顧

底部時間軸可拖曳回溯過去 24 小時。**整個介面跟著回到那個瞬間** —— 事件列表、態勢統計、地圖著色、甚至天體位置與日照都會一起回捲。

即時性圖層（航班、衛星、船舶）在回顧模式下會自動隱藏，因為它們只有「現在」的位置，沒有歷史軌跡。

### 🗺 地圖模式

地表著色一次只用一種，避免多重填色互相干擾：

| 模式 | 呈現 |
|---|---|
| **無** | 僅顯示邊界輪廓 |
| **政治** | 中性四色分區，純粹為了辨識，不帶任何含意 |
| **態勢** | 各國最嚴重的現行事件等級 |
| **活動量** | 各國事件數量的漸層濃度 |

### 📡 疊加圖層

可同時開啟，因為點與線不會爭奪地表：

- ✈️ **航班**（ADS-B 即時位置）
- 🛰 **衛星**（TLE 軌道推算）
- 🚢 **船舶**（AIS）
- ⚔️ **衝突前線**
- 📍 **標記與連線**（自行在場景上釘選、連結、註記）

### 🗂 情報面板

點擊任何東西都會打開對應面板，並可**獨立彈出成單獨視窗**放到第二螢幕：

- **事件面板** —— 標題與摘要、相關事件時間軸、涉入方、標籤、來源連結、縮圖；可加註個人筆記、加入書籤、匯出為 Markdown
- **地區面板** —— 分成「概況／事件／背景」三個分頁：國旗與基本資料、穩定度、經濟結構、維基百科摘要，以及該地區的完整事件清單
- **天體面板** —— 物理數據與百科摘要
- **實體面板** —— 人物、組織、地點的百科資料，可搜尋、可同時比對多個
- **多實體情境** —— 把最多 8 個事件、人物、地區、天體收集在一起，向 AI 提問它們之間的關聯。除了各面板上的收集按鈕，也可以直接在提問框裡用 `@` 指名：國家、報導提到的人物與事件會即時列出，feed 沒提過的名字則退回維基百科搜尋

### 🤖 本機 AI 分析

- **自動分類**：每則新聞由本機模型判定類別、嚴重度、地理位置、涉入方與可信度
- **座標解析**：模型大約有一半的地面事件只給得出地名而給不出座標，所以地名會在分類當下經
  伺服器地名表（`server/src/data/gazetteer.ts`）解析成座標並寫入資料庫，前端只負責讀取。
  每筆事件都帶一個 `geo_precision` 標明來源：`exact`（模型給的點）、`centroid`（由地名查出）、
  `region`（「歐洲」「Global Tech Sector」這類真實範圍，但沒有單一座標）、`none`（無法解析）。
  `region` 與 `none` 分開記錄是刻意的 —— 前者是「不該有圖釘」，後者是「該有但沒查到」。
  既有資料可用 `cd server && npx tsx ../scripts/backfill-geo.ts --dry-run` 檢視、去掉旗標後回填。
- **面板對話**：每個面板都能就當前主題提問，並附有自動生成的建議問題
- **畫面分析**：可截取當前場景交給多模態模型解讀
- **定期簡報**：定時彙整當前高熱度事件成情勢摘要

### 🔍 篩選與檢索

- 九個類別開關，各自顯示事件數
- 時間範圍（預設 6 小時，讓開啟畫面呈現「當下」而非積壓的歷史）
- 全文搜尋
- 書籤 / 關注清單
- 排序：最新 / 熱度 / 嚴重度
- 篩選組合可存成預設集重複套用

### 🌐 雙語

介面、事件標題與摘要皆為**中英雙語並存**。切換語言是即時的欄位切換，不需要重新分析或等待。

### ⚙️ 個人化

介面縮放、啟動視角、裝飾動效開關、警報音效與音量、星雲濃度、語言 —— 全部可在設定中調整並保留。

另有 **精簡模式**（收合側欄）與 **沉浸模式**（全螢幕場景，僅保留浮動工具列）。

### ⌨️ 鍵盤快捷鍵

| 按鍵 | 功能 |
|---|---|
| `/` | 聚焦搜尋框 |
| `[` `]` | 上一則 / 下一則事件 |
| `B` | 加入或移除書籤 |
| `I` | 切換沉浸模式 |
| `Esc` | 關閉面板 / 取消選取 |
| `?` | 顯示快捷鍵說明 |

## 事件分類

| 圖形 | 類別 | 涵蓋範圍 |
|---|---|---|
| ⚔ | `ARMED_CONFLICT` | 武裝衝突、軍事行動 |
| ⚑ | `POLITICAL` | 選舉、政變、外交、制裁 |
| ◆ | `ECONOMIC` | 市場、貿易、能源價格 |
| ☰ | `SOCIAL` | 社會運動、示威、人道危機 |
| ⚛ | `SCIENCE_TECH` | 科技突破、AI 發展、研究 |
| ❋ | `ENVIRONMENT` | 氣候事件、自然災害 |
| ✚ | `HEALTH` | 疫情、公衛事件 |
| ⬡ | `CRIME_SECURITY` | 網路攻擊、恐怖主義、跨國犯罪 |
| ✦ | `SPACE` | 太空任務、星際天體、撞擊預警 |

事件的存活時間由**熱度分數**決定，而非固定期限：高嚴重度、多方證實、或持續被後續報導提及的事件會自動延長保留，冷卻的事件則較快淘汰。

## 快速開始

需要 [Ollama](https://ollama.com) 在本機執行。

```bash
ollama pull gemma4:e4b
```

```bash
npm install
cp .env.example .env
npm run dev
```

前端啟動於 `http://localhost:5173`，後端於 `3001`。RSS 來源清單維護在 `server/src/config/feeds.ts`，不需要任何 API 金鑰。

> Windows 若 `better-sqlite3` 編譯失敗，需安裝 [Visual Studio Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/) 並勾選「使用 C++ 的桌面開發」。

船舶圖層需要 [aisstream.io](https://aisstream.io) 的免費金鑰（`AISSTREAM_API_KEY`），未設定時該圖層停用，其餘功能不受影響。
